# Meus Sites Favoritos

Uma página simples em HTML com links para alguns dos meus sites favoritos.

## Sites incluídos

- YouTube
- Google
- Aprenda Mais
- WikiHow
- Gemini

## Como visualizar

Abra o arquivo [`index.html.html`](./index.html.html) em um navegador. Não é necessário instalar dependências ou executar um servidor.

## Arquivos do projeto

- `index.html.html`: conteúdo da página.
- `youtube_logo.jpeg`, `Google_logo.png`, `Aprenda_mais_logo.png`, `wiki_how_logo.png` e `Gemini_logo.png`: imagens usadas na página.
